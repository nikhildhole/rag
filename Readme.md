What is RAG?
Full form of RAG is retrival agumental generation. When we add anything knowledge to LLM to beside it train while inference time it is RAG. So this additaion knowledge can come from internet search, vector search, sql, etc result.

Where to use RAG?
RAG is used in LLM power system to provide knowledge where LLM is not train on it or doesn't know about.

Why to use RAG?
To provide current or specific knowledge which LLM doesn't know we need to use RAG for it.
